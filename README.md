# Skills

A collection of skill packs for consistent, high-quality developer workflows.

## Skills

### `my-code-review`

High-signal, multi-perspective code review workflow for prioritized, actionable feedback.

Covers pull requests, branch/commit diffs, staged changes, and targeted file reviews. Reviews are structured around seven lenses (correctness, architecture, security, performance, testing, API compatibility, operability) with clear severity levels and a merge verdict.

### `publish-changes`

Prepare and publish local repository changes as a draft GitHub pull request.

Detects changes from git, runs a code review before publishing, fills a PR template from the diff, and creates or updates a draft PR using the `gh` CLI. Includes support for PR templates, Jira ticket context, and manual testing notes.
